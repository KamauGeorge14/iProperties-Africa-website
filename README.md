# iPropertiesAfrica Website

Official website source for iPropertiesAfrica.  
This project is a premium, responsive real estate site focused on the Kenyan market.

## Highlights

- Clean, modern UI with black-and-gold brand styling
- Mobile-first responsive layout
- Featured property cards with polished interactions
- Contact section with inline form validation feedback
- Testimonials and embedded video gallery
- Accessibility improvements (skip link, reduced-motion support, keyboard-friendly navigation)

## Stack

- HTML5
- CSS3
- Vanilla JavaScript (ES6+)
- Optional local static server via `serve` or `live-server`

## Run Locally

```bash
git clone https://github.com/KamauGeorge14/iProperties-Africa-website.git
cd iProperties-Africa-website
npm install
npm run dev
```

Alternative:

```bash
npm run start
```

## Project Files

- `index.html` - Main website markup
- `styles.css` - Design system, responsive styles, and animations
- `script.js` - Navigation, reveal effects, and form behavior
- `property-placeholder.svg` - Fallback listing image asset
- `server.js` / `test-server.js` - Optional Node static-server scripts
