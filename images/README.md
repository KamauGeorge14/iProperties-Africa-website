# iPropertiesAfrica Image Guide

This folder is reserved for production image assets.

## Priority Assets

1. Featured listing photos (high quality, real properties)
2. Team/office imagery for trust and brand credibility
3. Any campaign-specific banners or promotional visuals

## Recommended Specs

- Listing cards: 1200x800px (3:2) or larger
- Hero/background media: 1920x1080px or larger
- Format: `jpg` for photos, `png` for graphics with transparency
- Compression target: under 350KB per listing image where possible

## Naming Convention

- `listing-lavington-01.jpg`
- `listing-kilimani-01.jpg`
- `listing-hurlingham-commercial-01.jpg`
- `hero-kenya-properties-01.jpg`

## Notes

- The project currently includes `property-placeholder.svg` as a fallback listing image.
- Replace placeholders with real listing media before launch for best conversion.
